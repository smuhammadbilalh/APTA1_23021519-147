Coursework for **Advanced Programming Techniques (APT)** — Assignment 1, Roll No. 23021519-147.

A console application that demonstrates core C# method and array concepts:

| Exercise | Concepts |
|---|---|
| **Array statistics** | `out` parameters, method **overloading** (`int[]` / `double[]`), overflow-safe sums |
| **Resize array** | `ref` parameters, `Array.Copy`, reference re-assignment |
| **Median (challenge)** | `params` arrays, sorting, even/odd length handling |

## ▶️ Run

```bash
dotnet run --project APTA1.csproj
```
